# Security policy

## Supported versions

Security fixes are released for the latest minor version of `@flycommerce/ui`.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: on this repository, open **Security → Report a vulnerability**. Don't open a public issue.

We aim to acknowledge reports within 3 working days and to ship a fix, or a plan, within 14 days. Once a fix is published, we credit the reporter in the release notes unless they'd rather stay anonymous.
